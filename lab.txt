Introduction
The purpose of this lab is for you to convert your file system to threaded file system allowing multiple users to interact with the file system at the same time. For this lab you will be explicitly asked to launch k threads, where k will be a command line argument.  Each of the thread will execute certain commands developed in previous tasks before terminating. When all the threads would complete their execution then the program will close and exit.
Each thread will read the instructions from a text file titled input_thread<x>.txt and redirect the output after execution of thread in file output_thread<x>.txt where x is the thread number
The format for input file for each of the commands will be as following:
Create <fname>
Delete <fname>
Mkdir <dirName>
chDir <dirName>
Move <source_fname, target_fname>
Open <fName,mode>
Close<Fname>
Write_to_file <filename>, text
Write_to_file <filename>,text, startLocation, size
Read_from_file <filename,start,size
fileObj.Truncate_file maxSize
Show_memory_map

You may require refactoring your design to accommodate changes. Please document the changes diligently.
